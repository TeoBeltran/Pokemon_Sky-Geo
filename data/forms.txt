#==============================================================================
# Datos de FORMAS para la Pokédex web
#------------------------------------------------------------------------------
# En Essentials los tipos/stats de cada forma están en los scripts del juego
# (Pokemon_MultipleForms), no en pokemon.txt. La web no puede leer los scripts,
# así que los datos van acá.
#
# Formato:
#   [NOMBREINTERNO,numeroDeForma]     (la forma 0 es la base)
#   Type1=...          (opcional)
#   Type2=...          (opcional, vacío = monotipo)
#   BaseStats=...      (opcional, MISMO orden que pokemon.txt: PS,Atq,Def,Vel,AtEsp,DefEsp)
#   Abilities=...      (opcional)
#   HiddenAbility=...  (opcional)
# Solo hace falta poner lo que CAMBIA respecto de la forma base.
#
# Las formas que se llamen "Ancestral" no se muestran en la web (solo el aviso).
#==============================================================================
